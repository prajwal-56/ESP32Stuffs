How it works
⌨
USB HID Emulation
The ESP32-S3 presents itself as a USB keyboard and media controller to the host machine. No drivers needed on the target.
📶
Wi-Fi Access Point
The device creates its own network — 
 Not Rubber ducky
 with a password 
 FS0ciety#
. Connect to it on any phone or laptop to open the control panel.
🌐
Web Control Panel
A single-page app served directly from the device. No internet required. Optimised for mobile — all controls are thumb-reachable.
💡
RGB Status LED
The onboard LED reflects device state in real time. Each mode has its own colour or blink pattern.
Control Panel — Pages
Keys ›
The main keyboard control page. All sections work together — latch a modifier first, then tap a key tile to send the combination.
Modifier latch Quick combos Control keys Arrow / Nav F1 – F12 A – Z grid 0 – 9 grid Custom text Per-char delay

Modifier latch — Tap Ctrl, Shift, Alt or Win to hold them down (button highlights). Tap a key tile — the combo fires. Tap the modifier again or hit Release All to clear. Useful for anything from Ctrl+Z to Ctrl+Shift+Esc.

Quick combos — One-tap shortcuts for the most common combos: Ctrl+A/C/V/X/Y/Z/S, Alt+Tab, Alt+F4.

Per-char delay — Drag the slider (0 – 200 ms) to slow down text injection. Useful for slow hosts that drop characters at full HID speed.
Payloads ›
Pre-built keystroke sequences for common tasks. Split into Windows and Linux sections.
Rick Roll Matrix screen Volume up System info Open settings Keyboard spammer Shutdown Reboot

Destructive actions (Shutdown, Reboot) require confirmation before firing. The keyboard spammer injects random characters at high speed and has a dedicated Stop button — it won't crash the web server.
Builder ›
Build a custom multi-step payload by tapping step types one at a time. No drag-and-drop — every interaction is a single tap, designed for phone use.
Type text Single key Key combo Delay Open Run Open Terminal Save & replay Live log

Saving — Give the sequence a name and tap Save. Sequences are stored in the phone's browser (localStorage) and survive page reloads. Tap a saved sequence name to load and run it immediately.

Execution — The full sequence is sent to the device as a single JSON POST to /builder/run. The device executes steps in order.
Status ›
Live device telemetry, polled every 3 seconds from the /status endpoint.

HTTP API
GET /key/:name›
Press a named key. Supports: enter, tab, esc, space, backspace, delete, insert, home, end, pgup, pgdn, up, down, left, right, f1–f12, wintap, alttab, altf4, ctrlaltdel, any single letter a–z, any digit 0–9.
GET /combo?[mod]=1&key=z›
Fire a key combination. Modifier flags: ctrl, shift, alt, gui. Any number can be combined. Example: /combo?ctrl=1&shift=1&key=esc sends Ctrl+Shift+Esc.
GET /modkey/:name›
Toggle a latched modifier (ctrl, shift, alt, gui) or release all with releaseall. Returns on or off as plain text.
POST /type›
Inject a text string. Body: application/x-www-form-urlencoded.
Fields: text (string), enter (0/1), delay (ms per character, default 0).
POST /builder/run›
Execute a custom sequence. Body: JSON array of step objects.

Step types:
{"type":"text","text":"hello"}
{"type":"key","key":"f5"}
{"type":"combo","mods":["ctrl"],"key":"z"}
{"type":"delay","ms":500}
{"type":"openrun"} / {"type":"openterm"}
{"type":"enter"} / {"type":"tab"}
GET /status›
Returns device telemetry as JSON: {"clients":1,"uptime":"00:04:12","heap":214,"ip":"192.168.4.1"}
